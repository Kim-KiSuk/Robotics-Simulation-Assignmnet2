## 연구 흐름 — 49·52페이지

1. 조교 config로 baseline을 학습·평가한다.
2. 실패를 접근·파지·운반·배치로 분류한다.
3. 진단된 원인 하나와 검증 가능한 가설을 정한다.
4. 한 번에 한 요인만 바꿔 통제 실험한다.
5. 성공률과 실패 유형 변화로 지지·기각을 판정한다.

선택 모델의 로드·추론 실행은 확인했다. 정식 100회 평가, 단계별 실패 진단, 단일 요인 통제 실험, 결과에 따른 결론은 아직 보완 항목이다. 모델이 학습되었다는 사실만으로 이 연구 흐름 전체가 끝난 것은 아니다.

## 고정 조건 — 50페이지

- 환경의 박스·장난감 위치 분포, 성공 판정, 종료 조건 변경 금지.
- 학습에 사용하는 직접 키보드 사람 시범 전체 합 최대 100개.
- 학습에 실제 사용하는 Mimic 성공 생성 시범 최대 1,000개. 실패 파일은 분석용.
- 학습 seed 101·111, 검증 seed 42, 조교 평가 seed는 비공개.
- rollout 100회, horizon 800. 학습 seed별 성공률의 평균·표준편차 보고.
- 비교 조건 간 epoch, batch, 체크포인트 선택 규칙을 맞추고 학습량 보고.

데이터 실험 이름은 AUTO-100·VAR-20·PACE-20이며 수집 방식은 별도 통계에 기록한다. 자동 데이터는 직접 수집 사람 시범으로 계산하지 않는다.

## 평가 항목 — 53페이지

연구 문제의 정량 진단, 가설, 실험 설계, 결과 분석·결론, 과업에 맞춘 독창성이 각 20점이다. 성공률 순위가 점수 기준은 아니다. 확인되지 않은 실패 원인이나 성능 향상을 결과로 기재하지 않는다.

## 발표 — 48페이지

7장 초안은 문제·진단 → 데이터 → 학습 방법 → 평가 방법 → 확인 결과 → 통제 실험 보완 → 결론·한계 순서로 구성한다. 최종 제출 전 정식 결과와 조원별 역할을 반영해야 한다.

공통 연구 질문과 실험 원칙

사람 시범으로 학습한 BC 정책은 Toy2Box에서 왜 성공률이 저조한가? 원인 하나를 진단하고 그 원인을 겨냥해 성공률을 높인다.

1. 조교 설정으로 baseline을 재현한다.
2. 실패를 접근·파지·운반·배치로 분류하고 원인 후보를 정량적으로 진단한다.
3. 한 가지 원인과 검증 가능한 가설을 선택한다.
4. 한 번에 한 요인만 변경한다. 데이터 수, 학습 조건, 체크포인트 선택 기준을 맞춘다.
5. 성공률과 겨냥한 실패 유형의 변화로 가설을 지지하거나 기각한다.

자료에 명시된 조건은 다음과 같다.

- 환경, 성공 판정, 종료 조건을 유지한다.
- 학습에 사용한 사람 시범 전체 합은 최대 100개이며 키보드로 직접 수집한다.
- 학습에 실제 사용하는 Mimic 성공 생성 시범은 최대 1,000개이다. _failed 파일은 분석용이다.
- 학습 seed는 101·111, 검증 seed는 42이며, 평가 seed는 조교가 별도로 관리한다.
- rollout 100회, horizon 800으로 평가한다. 학습 seed별 성공률의 평균·표준편차와 실패 유형 분포를 보고한다.
- 같은 비교에서는 epoch, batch, 체크포인트 선택 규칙을 동일하게 하고 실제 학습량도 보고한다.
- 서로 다른 길이의 시범을 비교한다면 전체 프레임 수와 gradient update 수 차이도 확인한다.
- 데이터 분할은 episode 단위로 하고, 동일 원본에서 파생된 생성 시범이 학습·검증에 섞이지 않도록 관리한다.

자동 수집 데이터는 자동 수집으로 기록한다. 멈춤이나 속도 변화를 추가하는 것만으로 직접 수집한 사람 시범이 되지는 않는다.

A. 데이터 품질·구성

A-1. 시범의 운반 높이 다양성이 박스 충돌을 줄이는가?

문제: 항상 비슷한 높이로 운반한 시범만 학습하면 파지 자세가 달라졌을 때 필요한 높이를 확보하지 못할 수 있다.

가설: 안전한 운반 높이를 다양하게 경험한 정책은 박스 테두리 충돌이 감소한다.

실험: 일정한 운반 높이의 시범과 여러 안전 높이를 사용하는 시범을 각각 수집한다. 시범 수, 초기 위치 분포, 조작자, 접근 순서와 파지 방법을 맞춘다. 데이터 구성만 바꾸고 정책·학습 설정은 유지한다.

측정: 전체 성공률, 운반 중 테두리 충돌률, 수평 이동을 시작할 때 트럭 바닥과 박스 상단의 높이 차이, 운반 시간.

판정: 성공률 향상과 함께 높이 부족으로 인한 충돌이 줄어야 가설을 지지한다. 과도한 상승으로 시간이 늘거나 다른 실패가 증가하는지도 보고한다.

A-2. 성공한 파지에서도 안정성의 차이가 학습 결과를 바꾸는가?

문제: 성공 시범에도 안정적으로 잡은 경우와 운반 중 미끄러지다 겨우 성공한 경우가 섞일 수 있다.

가설: 안정적인 파지 시범으로 학습하면 운반 중 낙하가 감소한다.

실험: 파지 후 손끝과 트럭 사이의 상대 위치·회전 변화를 측정한다. 초기 위치와 시범 수를 맞춘 안정 파지 그룹과 미끄러짐이 있는 성공 그룹으로 각각 학습한다. 안정성 구분 임계값은 평가 결과를 보기 전에 정한다.

측정: 파지 후 상대 위치·회전 변화량, 파지 성공률, 운반 중 낙하율, 전체 성공률.

판정: 안정적인 시범 그룹에서 운반 중 낙하가 줄어야 한다. 두 그룹의 파지 위치나 초기 조건이 달라 생긴 효과인지도 확인한다.

A-3. 회전과 위치 이동의 순서가 접근·파지 학습에 영향을 주는가?

문제: 같은 목표에도 회전 우선과 위치 정렬 우선은 서로 다른 중간 행동을 만든다.

가설: 특정 접근 순서가 자세 오차와 정책의 정체를 줄여 파지 성공률을 높인다.

실험: 같은 조작자가 두 순서로 수집한다. 조건 1은 안전 높이 → 회전 → XY 정렬 → 하강, 조건 2는 안전 높이 → XY 정렬 → 회전 → 하강이다. 최종 파지 자세, 시범 수, 초기 위치 분포와 조작 속도를 최대한 맞춘다.

측정: 접근 단계 정체 시간, 파지 직전 위치·각도 오차, 파지 성공률, 전체 성공률.

판정: 접근·파지 단계의 개선으로 효과를 설명할 수 있어야 한다. 어느 순서가 유리한지는 결과로 결정한다.

B. 데이터 증강 (Mimic)

B-1. 그리퍼 닫힘 명령과 실제 파지 완료 중 무엇을 구간 경계로 삼아야 하는가?

문제: 닫힘 명령 직후에는 트럭이 아직 고정되지 않았을 수 있다.

가설: 트럭이 손끝을 따라 움직이기 시작한 시점을 파지 완료 경계로 사용하면 파지·운반 연결이 개선된다.

실험: 같은 원본에서 그리퍼 명령 기반 annotation과 손끝–트럭 상대 자세 안정화 기반 annotation을 비교한다. 원본 선택, 생성 설정, 학습에 쓰는 성공 생성 시범 수를 맞춘다. 안정화 시점 계산은 annotation에만 사용한다.

측정: 생성 중 파지 직후 낙하율, 생성 성공률, 경계 전후 상대 자세 변화, 학습 정책의 파지→운반 전환 성공률.

판정: 구간 경계가 실제 파지와 더 잘 일치하고, 그 단계의 실패도 줄어야 한다.

B-2. Mimic 연결 경로가 박스 높이를 고려해야 하는가?

문제: 시범 조각 사이의 연결 경로가 낮게 지나가면 박스 테두리를 건드릴 수 있다.

가설: 연결 경로에 충분한 수직 상승 지점을 넣으면 운반 단계 실패가 감소한다.

실험: 기존 연결 방식과 필요 높이 확보 → 수평 이동 연결 방식을 비교한다. 연결 구간 총 프레임 수와 나머지 설정을 맞춰 경로 형상의 효과를 분리한다. 환경이나 성공 판정은 변경하지 않는다.

측정: 연결 구간 충돌률, 생성 성공률, 생성 경로의 최소 높이 여유, 학습 정책의 운반 단계 실패율.

판정: 생성 성공률 상승과 학습된 정책의 성능 상승을 각각 판정한다. 생성만 잘되고 정책은 개선되지 않을 수도 있다.

B-3. 같은 경로에서도 접촉 전후에 시간을 더 배분하면 학습이 쉬워지는가?

문제: 파지 직전과 릴리즈 직전에는 작은 위치 오차가 중요하다.

가설: 접촉 근처를 천천히 수행하는 생성 시범이 정밀 조작 학습에 유리하다.

실험: 경로와 전체 프레임 수를 유지하고 시간 배분만 바꾼다. 일정한 속도 조건과 자유 공간 이동은 빠르게·접촉 근처는 느리게 진행하는 조건을 비교한다. 생성 동작은 시뮬레이션에서 실제 실행하고 성공한 시범만 학습에 사용한다.

측정: 파지·릴리즈 직전 오차, 파지 성공률, 배치 성공률, 전체 성공률.

판정: 전체 길이를 늘린 효과와 구분해야 한다. 시간 배분 외 경로·원본·학습 데이터 수는 유지한다.

C. 관측·행동 표현

C-1. 쿼터니언 대신 연속적인 6차원 회전 표현을 주면 자세 학습이 개선되는가?

문제: 서로 부호가 반대인 쿼터니언은 같은 자세를 나타낸다. 표현 불연속이 데이터에 존재한다면 자세 학습을 어렵게 할 수 있다.

가설: 연속적인 회전 표현이 파지·배치 직전의 자세 오차와 회전 명령 진동을 줄인다.

실험: 먼저 인접 프레임의 부호 변화와 자세 오차를 진단한다. 같은 회전 정보를 쿼터니언과 회전행렬의 두 열로 구성한 6차원 표현으로 각각 입력한다. 출력 행동은 유지한다. 입력 차원 증가에 따른 파라미터 수 변화도 기록한다.

측정: 관측 회전 표현의 불연속 빈도, 파지·배치 직전 각도 오차, 회전 명령 진동, 성공률.

판정: 부호 불연속이 없다면 그 설명은 기각한다. 다른 표현의 장점과 부호 불연속 해결 효과를 혼동하지 않는다.

C-2. 박스를 넘을 여유와 입구에 들어갈 여유를 직접 알려주면 충돌이 줄어드는가?

문제: 물체 중심 좌표만으로는 트럭의 바닥이나 모서리가 박스에 걸리는지 학습하기 어려울 수 있다.

가설: 기하학적 여유량을 추가하면 운반·배치 판단이 개선된다.

실험: 기존 관측과 여유량을 추가한 관측을 비교한다. 추가 값은 트럭 바닥−박스 상단 높이 차이, 트럭 외곽−박스 입구 사이 최소 여유이다. 기존 자세 관측과 고정 물체 크기로 계산하며 학습·실행 시 동일한 계산을 사용한다. 회전된 박스의 좌표계도 반영한다.

측정: 높이 확보 전 수평 이동 비율, 테두리 충돌률, 배치 성공률, 전체 성공률.

판정: 성공률뿐 아니라 의도한 기하학적 실수가 감소하는지 확인한다. 정답 성공 여부를 관측으로 제공하지 않는다.

C-3. 움직임 정보를 주면 잡힌 상태와 미끄러지는 상태를 구별하는가?

문제: 비슷한 위치에서도 트럭이 손끝을 따라 움직이는지 떨어지고 있는지에 따라 필요한 행동이 다르다.

가설: 트럭 속도와 손끝–트럭 상대 속도를 알려주면 운반 중 낙하가 줄어든다.

실험: 기존 관측과 속도 정보를 추가한 관측을 비교한다. 속도는 과거·현재 위치 차이를 실제 제어 시간 간격으로 나누어 계산한다. 미래 프레임은 사용하지 않으며 episode 시작 처리도 학습·실행에서 동일하게 한다.

측정: 파지 후 헛들기 비율, 운반 중 낙하율, 미끄러짐 발생 이후 실패율, 전체 성공률.

판정: 미끄러짐 관련 실패가 감소하는지 확인한다. 차분 잡음이 새로운 문제를 만드는지도 분석한다.

D. 정책 구조·학습

D-1. 키보드 행동의 0 값 편중을 손실함수에서 보정하면 정체가 줄어드는가?

문제: 이동 중에도 여러 축의 명령은 0이다. 정책이 드문 이동 명령보다 0 예측을 지나치게 잘 배우면 필요한 움직임이 약해질 수 있다.

가설: 축별 0·비0 빈도를 보정한 학습이 목표 밖 정체를 줄인다.

실험: 데이터는 그대로 두고 기본 행동 학습 손실과 빈도 보정 손실을 비교한다. 그리퍼 손실은 유지한다. 현재 설정이 GMM 음의 로그우도라면 분포 기반 손실을 보존하는 가중 방식을 설계하거나, 동일한 결정론적 회귀 baseline 두 조건으로 비교한다. 모델·기본 손실까지 동시에 바꾸지 않는다.

측정: 필요한 방향 이동 명령의 크기, 목표 밖 정체 시간, 불필요한 이동 발생률, 성공률.

판정: idle 감소만으로 성공을 선언하지 않는다. 불필요한 움직임이나 진동 증가 없이 과업 수행이 개선되어야 한다.

D-2. 현재 작업 단계를 함께 배우게 하면 행동 예측이 개선되는가?

문제: 접근·파지·운반·배치를 충분히 구분하지 못하면 그리퍼 전환과 이동 방향을 혼동할 수 있다.

가설: 단계 구분을 보조 과제로 학습하면 행동 표현이 개선된다.

실험: 같은 정책에 단계 예측 출력을 붙이고 단계 학습 손실 적용 여부만 비교한다. 시범에서 학습용 단계 라벨을 만들되, 실행 시 정답 단계는 입력하지 않는다. 두 조건의 주 정책 구조와 학습 데이터는 동일하게 유지한다.

측정: 단계별 행동 오차, 너무 이른 릴리즈와 늦은 닫힘 발생률, 단계 예측 혼동행렬, 전체 성공률.

판정: 단계 예측 정확도만 높아지는지, 실제 단계 전환 실패도 줄어드는지 구분한다.

D-3. 그리퍼 끝점의 공간 오차를 학습하면 배치가 정밀해지는가?

문제: 이동량과 회전량의 숫자 오차가 작아도 그리퍼 끝에서는 큰 위치 오차가 생길 수 있다.

가설: 공간상의 오차를 보조 학습 목표로 줄이면 정밀 배치가 개선된다.

실험: 기존 행동 학습 손실과 공간 오차를 추가한 손실을 비교한다. 현재 손끝 자세에 예측·정답 상대 명령을 적용하고, 그리퍼 주변 가상 기준점들의 목표 위치 차이를 계산한다. 실제 RMPFlow 실행 결과를 미분한다고 가정하지 않는다. 출력 표현과 개폐 학습은 유지한다.

측정: 배치 직전 위치·각도 오차, 트럭 모서리의 입구 여유, 테두리 접촉률, 성공률.

판정: 계산한 목표 자세의 정확성과 실제 실행 정확성을 구분한다. GMM 정책에서는 대표 명령을 사용하는 보조 손실의 정의를 먼저 고정한다.

후보를 선택하는 기준

| baseline에서 관찰한 주된 실패 | 우선 검토할 후보 |
|---|---|
| 트럭을 충분히 들지 않고 박스로 이동 | A-1, B-2, C-2 |
| 닫힘 이후 헛들기·미끄러짐 | A-2, B-1, C-3 |
| 접근 중 회전 혼동·정체 | A-3, C-1, D-1 |
| 그리퍼 전환 단계 혼동 | D-2 |
| 배치 직전 정밀도 부족 | B-3, C-2, D-3 |

위 표는 선택 기준이며 성능 순위가 아니다. 진단 결과와 구현 가능한 측정 지표를 기준으로 한 주제를 정한다.

계획서 작성 양식

1. Baseline 실패 진단: 100회 중 어느 단계에서 몇 회 실패했는가?
2. 연구 질문: 바꾸려는 요인 하나는 무엇인가?
3. 가설: 어떤 실패 유형이 왜 감소할 것으로 예상하는가?
4. 비교 조건: 무엇만 바꾸고 무엇을 동일하게 유지하는가?
5. 평가: 성공률, 관련 실패율, 시간, 학습량을 어떻게 측정하는가?
6. 판정 기준: 실험 전에 정한 개선 기준과 가설 기각 조건은 무엇인가?
7. 한계: 다른 설명, 계산량 증가, 데이터 편향은 무엇인가?
